3. Execution Trace • Top 5 Best-Selling Shoe Models
User Query
“What were our top 5 best-selling footwear models last month by sales revenue and quantity?”
1 search_semantic_catalog (keyword="footwear model sales revenue")
Metric Discovery
• Product Dimension → mdm_dim_product_size_info (model: Cloudmonster, Cloudsurfer, Cloud 5...)
• Metrics → Revenue = SUM(total_paid), Quantity = SUM(sales_qty)
• Join & Filter → Join on sku; Mandatory filter: is_valid_data = 1 AND category = 'Footwear'
2 describe_table (table_name="dws_fact_channel_store_sales_order_detail")
Partition Check
• Partition Key: ds (YYYYMMDD) • Target Month: ds >= '20240901' AND ds <= '20240930'
3 execute_sql
Guardrails Passed 
SELECT
  p.model AS shoe_model,
  SUM(o.total_paid) AS total_revenue,
  SUM(o.sales_qty) AS units_sold,
  ROUND(SUM(o.total_paid) / NULLIF(SUM(o.sales_qty), 0), 0) AS avg_unit_price
FROM dws_fact_channel_store_sales_order_detail o
JOIN mdm_dim_product_size_info p
  ON o.sku = p.sku
WHERE o.ds >= '20240901'
  AND o.ds <= '20240930'
  AND o.is_valid_data = 1
  AND p.category = 'Footwear'
GROUP BY
  p.model
ORDER BY
  total_revenue DESC
LIMIT 5;
